DuckDive

A Python library that turns a pandas DataFrame into a single self-contained HTML file with a fully interactive, SQL-native data table. Every demo below is one .html — data, UI and logic, no server, no network.

Sales demo — JSON mode 1,200 rows

Custom template with two cross-filtered tables (raw + grouped SQL view), four live SQL labels, standalone filter buttons and exclusion toggles. All operations run client-side on embedded JSON.

Sales demo — WASM mode 200,000 rows

Same template, but data lives in an embedded parquet queried by duckdb-wasm in a Web Worker: search, filters, sorting, paging and export all run as SQL in the browser. Scales to millions of rows.

Row atoms, cell popups & redaction WASM

Select rows in the first table and the grouped view below filters to the selected regions (use_filter_keys). Click a product cell for a custom formatter popup. The channel column is masked at build time — raw values never reach the HTML.

Multi-table + bound params JSON

DuckDive({"t": orders, "regions": managers}) — a SQL view JOINs two registered tables, and :min_amt is bound at build time for per-recipient reports.
